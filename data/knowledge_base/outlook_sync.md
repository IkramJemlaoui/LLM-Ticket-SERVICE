# Outlook Calendar Sync Troubleshooting

If a user reports that calendar items created on one device do not appear on another, first confirm:
- whether the same account is signed in on both devices
- whether the device has network access
- whether the Outlook app is in offline mode
- whether the issue affects calendar only or also email

Suggested first reply:
Ask for the affected device type, when the issue started, and whether signing out and back in resolves the sync problem.

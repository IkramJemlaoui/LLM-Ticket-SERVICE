# Optional Investor Deck Outline

This deck is optional supporting material. It does not replace the assignment's one-slide one-pager or five-page architecture document.

## 1. Investment thesis

**AegisDesk AI:** evidence-first agentic operations for faster, safer IT support.

- five specialist agents;
- visible evidence and decisions;
- mandatory human release;
- four-week, one-queue proof of value.

## 2. Cost of the current workflow

- incomplete tickets create repeated clarification;
- agents reread, reclassify, search and redraft common cases;
- knowledge fragmentation creates rework and SLA risk;
- opaque AI alternatives create privacy, hallucination and overtrust risk.

Use customer baseline data before quantifying annual cost.

## 3. Product experience

Show the real Streamlit application—not a generated imitation:

- ticket and business impact;
- agent recommendation;
- editable grounded draft;
- evidence/quality confidence;
- agent trace and approval gate.

## 4. Agentic advantage

Safety → Triage → Knowledge → Resolution → Risk/Quality → Human.

Explain separate roles, typed handoffs, stop/escalate/await/review decisions, maximum six steps, and why deterministic controls surround model calls.

## 5. Architecture and trust

Use the assignment's six layers: Business; Agentic/Application; LLM; Data; Governance/Risk/Compliance; Operations/Monitoring. Show field-level PII minimization, approved-KB boundary, output provenance checks and metadata-only telemetry.

## 6. Measurable business case

Label every figure as baseline, pilot target or measured result:

- target −40% time to first qualified draft;
- target −25% triage rework;
- target ≥60% acceptance without material rewrite;
- safety target: zero autonomous sends.

ROI = minutes saved × eligible volume × loaded labor cost − run cost.

## 7. Feasible pilot

- Week 0: baseline, labelled set, governance sign-off and training.
- Weeks 1–2: shadow mode on one support queue.
- Weeks 3–4: assisted mode with mandatory approval.
- Gate: stop, refine or scale using quality, safety, adoption and cost evidence.

## 8. Scale thesis and ask

**Current:** Light Streamlit workspace, SQLite persistence, smart intake, urgency ranking, accountable cross-department routing, visible similar-case solutions, approved tips, and TF-IDF top-3 RAG over 20 articles and 16 verified cases.<br>
**Roadmap:** SSO/RBAC, ITSM API, managed monitoring, evaluated hybrid retrieval.

Ask for one queue, a named sponsor, approved knowledge/data, security/privacy participation, and four weeks to prove value.

## Presentation rules

- use only real application screenshots;
- never present targets as measured outcomes;
- label implemented versus roadmap capability on every technical slide;
- cite external frameworks/tools and acknowledge GenAI assistance;
- keep the live narrative under five minutes unless instructed otherwise.
